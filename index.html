Import Master Item dari SOH

Dilakukan oleh Cost Control, sekali sebelum SO dimulai. Format didukung: .txt (VHP desktop/legacy) dan .csv (VHP cloud: TSBK, TPI, TSD). File dibaca di alat ini saja, tidak dikirim ke mana pun.

Ambil Master dari Server

Master item disiapkan Cost Control dan disimpan di server (GitHub). Butuh sinyal — lakukan sekali saat masih di area bersinyal. Setelah tersimpan, app bisa dipakai penuh tanpa internet.

Pilih Unit & Store

Satu petugas = satu Store. Pembagian per store mencegah item terhitung dua kali dan membuat hasil gabungan bisa dipisah per store.
